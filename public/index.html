            Board tools

            Cheat sheet

            DBG_WATCH(x)
            live value in the Watch table + plot
            DBG_BREAK()
            pause until Continue
            DBG_BREAK_IF(c)
            pause when c is true
            DBG_ASSERT(c)
            report + pause when c is false
            DBG_LOG("…")
            message in the Debug log
            DBG_TRACE()
            record that this function ran
            DBG_MEMORY()
            watch free RAM / heap

            ESP32 crashes ("Guru Meditation Error") are decoded automatically in the Debug tab after you compile in this session.

              Compile settings
              
      
              Code is compiled for free on GitHub Actions (about 15 s – 2 min per build), or on a compile server you host (seconds).
              
      
              
        GitHub Actions (free)
        
        
        
              
          Create a fine-grained token:
          Repository access → Only select repositories → that repository; Permissions → Actions and Contents: Read and write.
          The token is stored only in this browser. Other people: fork the repo and use your fork.
